# Easy Suite brand assets

Generated by the Easy Suite brand script (pixel logos, banners, social previews). Same frame, palette and
fonts across all seven tools; only the icon and accent colour change.

| File | Use |
|---|---|
| `banner-*.png` (1280×320) | README header |
| `social-*.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-*.png` (240×240), `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). Banner art is real output of the Easy tools.
